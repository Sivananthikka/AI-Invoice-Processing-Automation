# AI-Based Invoice Processing & Automated Approval Workflow

An AI-powered invoice processing workflow built using **n8n, Gmail, and Google Sheets**.

### Features
- Automated invoice processing from Gmail
- PDF invoice data extraction
- AI-based invoice analysis
- Invoice validation and risk scoring
- Automated approval status
- Google Sheets record storage
- Automated email notifications

### Workflow
Gmail → PDF Extraction → AI Analysis → Validation → Risk Scoring → Google Sheets → Email Notification

### Technologies
**n8n | AI Agent | Gmail | Google Sheets | Workflow Automation**
